# Each case starts with its own array. Here is one complete example, explained line by line.
#
#   5 2
#   0 0 0 0 0
#   U 3 4 1 1
#   Q 3 4
#
# Line 1   5 2
#   5 = how many elements are in the array.
#   2 = how many operation lines follow the array. Here they are one update and one query.
#
# Line 2   0 0 0 0 0
#   These are the five starting values, written from left to right.
#   Index:  0  1  2  3  4
#   Value:  0  0  0  0  0
#
# Line 3   U 3 4 1 1
#   U means update. Read the four numbers in this order:
#   3 = first index to change (fourth element, because counting starts at 0).
#   4 = last index to change (fifth element). Both ends are included.
#   First 1 = multiply each selected value by 1.
#   Last  1 = then add 1 to each selected value.
#   Each selected zero becomes 1 * 0 + 1 = 1. The array is now [0, 0, 0, 1, 1].
#
# Line 4   Q 3 4
#   Q means query. Read the current values from index 3 through index 4: [1, 1].
#   The answer has three numbers, in order: minimum, maximum, sum modulo 998244353.
#   Here the answer is 1 1 2 because the smallest and largest are 1, and 1 + 1 = 2.
#
# Quick reference for the remaining cases
#   U left right gain offset    New value = gain * old value + offset at each selected index.
#   Q left right                Report minimum, maximum, and sum modulo 998244353.
#   S left right                Report just the sum modulo 998244353.
#   For the sum, use a remainder between 0 and 998244352. For example, -1 gives 998244352.
#   A line beginning with # EXPECTED shows the answer to the query directly above it.
#   When reading this file in a program, skip blank lines and all lines starting with #.
